Contains the flatbuffers schema that defines the structure of auto-generated structs.

This game engine should have schemas that define the following:
## ECS
- Components
- Scenes
## UI
- UIWidgets
## Databases
- Graphics
- Audio
- ex. Gameplay (DBs of Personas, Enemies, Skills, BattleStats, ShopItems, etc.)
## Scripting/Events
- Ex. Scene scripting, dialogue scripting, enemy ai scripting
